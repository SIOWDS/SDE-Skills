**SDE Skills** is an open-source collection of reusable AI-agent skills based on **SDE Ontology (Show–Difference–Entanglement / 显露—差异—纠缠)**, created by **Dr. Desheng Wang (王德生博士)**.

> The world is not merely discovered. It emerges: **in E, through D, S emerges.**

## Why SDE Skills?

Most prompt collections tell an AI what to say. SDE Skills give an AI a reusable way to diagnose how knowledge, research and systems emerge, change and stabilize.

- **S — Show / 显露**: the currently recognizable state
- **D — Difference / 差异序列**: the path of variation, selection, revision and convergence
- **E — Entanglement / 特征纠缠**: the enabling and constraining field
- **Three equations**: `S=F(D,E)`, `D=G(S,E)`, `E=H(S,D)`
- **Core proposition**: 在 E 中，经 D，成 S

## Install

Copy any skill folder into the skills directory supported by your AI coding or agent environment. Each folder contains a self-contained `SKILL.md`.

Example:

```bash
git clone https://github.com/SIOWDS/SDE-Skills.git
```

Then copy the skill you need, for example `skills/sde-ontology/`, into your agent's personal skills directory.
