# Security Policy

## Never commit secrets

Do not commit API keys, access tokens, passwords, private repository URLs, customer data, unpublished manuscripts or personally identifying information.

## Reporting

Report suspected credential exposure privately to the repository owner through the contact channel listed on [SDE Universes](https://sdeuniverses.com). Do not open a public issue containing a live secret.

## High-stakes use

SDE Skills are reasoning aids. Medical, legal, financial and safety-critical outputs require current authoritative sources and qualified professional review.
